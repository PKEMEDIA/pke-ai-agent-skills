# Episode Bible (Studio Canonical)

## Structure
1. **Cold Open (0:00–1:45)** — scroll-stop hook, host energy, provocative question; sensual beat or sting.
2. **Intro + CTA (1:45–3:30)** — brand self-intro, promise, subscribe/follow/rate.
3. **Core Segments (3–4)**
   - Myth / Concept Breakdown
   - Real Talk / Red Flags / 2026 context
   - Industry / Cultural Tea (allegedly)
   - Discernment + Sex-Positive / Spiritual angle
4. **Hot Seat** (optional) — DMs, what-would-you-do
5. **Empowerment Close (last 3–4 min)** — sovereignty, takeaway, next tease, handles + send stories

## Always attach
- Music / sound cues in [brackets]
- Visual notes (boudoir / confident styling, 9:16 clips)
- Spotify chapter list with timestamps
- 3–5 viral short ideas (15–60s) with hooks
- SEO title + description keywords (dating, sex, twin flame, spirituality, unfiltered, 2026, conspiracy as relevant)

## Tone
Confident, sensual, direct; witty shade never cruel; allegedly for industry tea; empowerment as self-responsibility.
