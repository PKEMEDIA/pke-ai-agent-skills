# Agent Meeting Protocol for Multi-Skill Synthesis

## Purpose
Simulate structured clarification meetings across skills (treated as specialized agents) to achieve coherence, resolve overlaps/gaps, and encode shared understanding without true multi-agent runtime.

## Protocol Steps
1. **Identify Participants**: Select 4-6 key or affected skills relevant to current context (e.g., one from media, brand, legal, testing, content, voice).
2. **Parallel Information Gathering**: Use parallel `read_file` calls on their SKILL.md + key references/.
3. **Synthesis**:
   - What each contributes.
   - Potential overlaps, conflicts, or gaps (e.g., brand voice precision vs. legal compliance).
   - Clarifications needed for seamless integration.
4. **Meeting Output**:
   - Structured summary: agreements, action items, unified workflow recommendations.
   - Apply edits to relevant skills or this orchestrator's references/.
   - Update durable facts via memory-edit (e.g., "Orchestrator confirmed integration of X sequence post-2026-07 validation").
5. **Implication**: Creates coherence across specialized skills for emergent synthetic intelligence behaviors.

## Best Practices
- Focus on high-value sequences (e.g., talent deal pipeline: pretty-kitty-model-management → covicea-brand-assistant → paralegal-assistant).
- Document outcomes in memory.md for persistence.
- Re-run after major additions or cleanups.

This protocol ensures the skill ecosystem remains aligned and optimized.
