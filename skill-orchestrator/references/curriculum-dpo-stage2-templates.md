## Caption rules

1. WIN always includes the locked block + explicit correct-structure language.
2. LOSE always names the defect (fused, elongated, melted, wrong scale, etc.).
3. Keep lighting + oil language on the WIN side so the model does not learn “good anatomy = flat plastic”.
4. Same approximate crop/pose family per pair → strongest preference gradient.
5. Prefer real production failures as LOSE images over generic bad samples.
6. Tag all of these **Medium** (Stage 2). Mix ~20–30% Stage 1 framing pairs so artistic legitimacy is retained.

**Volume target Stage 2:** ~40–60 hand + ~40–60 proportion + ~40–60 intimate → path to 150–250 total pairs.

### Naming convention

```
s{stage}_{category}_{variant}_{index}

stage:     1 | 2 | 3
category:  frame | hand | prop | int | skin | oil | id
variant:   open | body | grip | two | recline | lowangle | seated | torsoarm
           soft | erect | close | hand | duo
index:     001, 002, ... (zero-padded)
```

Examples: `s2_hand_open_014.png`, `s2_prop_lowangle_008.png`, `s2_int_erect_003.png`

**Chosen and rejected share the same stem.**  
OneTrainer DPO Pair Tool matches on filename stem.
