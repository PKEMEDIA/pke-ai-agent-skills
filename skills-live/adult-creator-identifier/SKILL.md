# Adult Creator Identifier

Structured workflow for identifying anonymous or unknown individuals in adult videos, photos, and clips. Combine visual/audio clue extraction, specialized reverse-search tools, platform tactics, and ethical guardrails. Use when general search is insufficient.

## Workflow

**1. Extract every clue first**
- Tattoos: exact text, font/style, placement, colors, nearby ink
- Body markers: scars, birthmarks, piercings, nails, hair patterns, muscle definition
- Audio: exact phrases, accent, tone, background noise
- Environment: walls, furniture, windows, reflections, readable text
- Technical: watermarks, captions, metadata if available
- Capture targeted screenshots (tattoo close-up, face if visible, full context)

**2. Search by uniqueness order**
- Unique tattoo/text: `"exact tattoo text" tattoo onlyfans OR porn`
- Audio phrases: exact quote + video/onlyfans
- Visual: BabeCheck.org, FaceDigger.com, FaceCheck.id; Yandex Images for NSFW
- Communities: r/pornID (follow formatting), r/tipofmypenis
- Platforms: OnlyFans username guesses; OnlyFinder / FindaPeach for niche attributes
- Reverse video tools (e.g. FrameTrace) for original uploads

**3. Layer evidence**
- Exact tattoo + body type → high confidence
- Multiple independent clues → very high
- Face-only on low quality → medium; verify other traits
- No matches after thorough search → unidentified amateur/private (common)

**4. Special cases**
- Face hidden / back-side POV → prioritize tattoos and body features
- Leaked/reposted → hunt original date/source; credits often stripped
- Suspected AI → tattoo inconsistency across frames, unnatural motion, robotic audio
- Fully anonymous → conclude not publicly identifiable

**5. Ethics (never skip)**
- Respect intentional anonymity
- No doxxing, harassment, or real-life exposure
- Non-consensual leaks: note but do not redistribute
- Stop if identification risks harm
- Always state confidence level and sources

**6. Output structure**
- Confidence: High / Medium / Low / Unidentified
- Key matching clues
- Profile links or usernames (with verification note)
- Next steps or missing clues
- Ethical disclaimer when appropriate
