# Grok Usage Maximizer

Strategic orchestration of SuperGrok / SuperGrok Heavy weekly compute pools. Prefer high-leverage heavy work over scattered low-value queries.

## How usage is metered

- **Compute-metered weekly pool** (Settings → Usage), not simple message counts.
- Counts prompt tokens (history + system + tools + image/audio encodings), reasoning tokens, completion tokens.
- Heavy drain: long context, DeepSearch, tool loops, Imagine quality/high-res, multi-agent, extended voice.
- Breakdown: Chat, Imagine, Voice, Build, API.
- Exhaustion pauses paid features until weekly reset; free-tier fallback may remain. Extra credits top up immediately.
- Consumer app pool ≠ xAI Console/API billing (separate ledger).

**Implication**: Burn pool on chains that produce portfolio-ready or decision-grade output.

## Core principles

1. **Value density** — one deep research + synthesis session beats dozens of shallow queries  
2. **Multipliers** — memory, long context, parallel tools, iterative refine loops  
3. **Interface synergy** — route tasks to the surface that spends compute efficiently (see references/interface-playbooks.md)  
4. **Monitor** — check Usage before/after heavy phases; plan around weekly reset  
5. **Trigger depth** — explicitly request full reasoning, DeepSearch, agentic tool workflows, iterative image refinement  

## Prompt techniques

- Phase structure: "Step 1 research… Step 2 parallel tools… Step 3 synthesize + assets"  
- Request full reasoning / agentic mode for heavier internal compute  
- Upload references early for vision grounding  
- Chain: "Using previous analysis, generate X and edit Y"  
- After core task: variations + production package  
- Avoid one-word follow-ups that drain inefficiently  

## Risk mitigation

- Watch pool % live during heavy sessions  
- Near limit: pause non-critical steps, buy credits, or shift light work to free tier  
- Waste sources: verbose history without memory pruning; re-uploading same images  
- Aggressive parallel tools can hit TPM/RPS before pool exhaustion
