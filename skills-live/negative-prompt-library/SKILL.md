## How to Use This Library

- Start with the **Core All-Purpose** set.
- Add category-specific blocks as needed (Skin, Hair, iPhone).
- Keep negatives concise but comprehensive — place after your positive prompt.
- For mulatto subjects: always include the Mulatto Skin and Mulatto Hair additions.
- For iPhone selfies: always include the iPhone Selfie block.
- For maximum non-silky textured hair: combine Core + Hair block + Non-Silky additions.

This library eliminates the most common photorealism-breaking artifacts while preserving natural texture, undertones, curl physics, and authentic iPhone camera characteristics.
