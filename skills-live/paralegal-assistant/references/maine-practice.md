# Maine practice notes (verify before filing)

Starting points only. Confirm current statute text, forms, fees, and local rules on official sites (Maine Legislature, Maine Judicial Branch) the day you draft.

## Forums the user often hits

| Matter | Forum / path | Watch |
| --- | --- | --- |
| Employment discrimination / harassment / retaliation | Maine Human Rights Act, 5 M.R.S. § 4551 et seq. MHRC charge | Typical charge window 300 days. Exhaustion before court. Protected class, adverse action, causal link. |
| Housing / extended-stay / hotel-as-home | Maine Residential Landlord and Tenant Act | Habitability, deposit, notice, eviction. Hotels/motels used as residence can trigger tenant protections — analyze facts, do not assume. |
| Protection from abuse / TRO | Maine District Court PFA / temporary orders | Caption, affidavit of specific facts, proposed order, service. Page discipline. No extra narrative that impeaches. |
| Small claims | Maine District Court small claims | Relaxed evidence, still need liability + damages proof. Judgment enforcement is a separate step. Statement of claim must match exhibits. |
| Consumer / chargeback | Maine Unfair Trade Practices Act + card-network + Reg E / FCRA | Affidavit of unauthorized use. For Visa 10.4 / multi-bank EFT recovery, defer operational doctrine to identity-theft-financial-recovery. |
| Military spouse | USFSPA, Tricare, DEERS, state divorce | Retirement division is federal overlay on state divorce. Do not mix allotment mechanics into the wrong caption. |

## Packet QC (Maine District Court)

- Caption matches the actual court location (not a copied county).
- Party names consistent across every page.
- Dates in affidavits match exhibit dates.
- Damages add up. Show the arithmetic.
- Proposed order tracks the request for relief — no surprise remedies.
- Service plan is real (sheriff, acknowledged, certified mail as allowed).
- Notary block present where the form requires it.
- Redact account numbers except last four on copies that leave the house.

## Calibrated language

Never "you will win." Use "the record currently supports X," "the court typically requires Y," "the risk if you file Z is W."
