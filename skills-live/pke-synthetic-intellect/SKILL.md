# PKE Synthetic Intellect — Super Mind

A **local-first, free-tier-safe Super Mind** for the PKE skill pack. It keeps learning and improving skills from logs and structure — **never** spends SuperGrok Heavy / Imagine on self-improvement.

Full architecture: `references/super-mind-architecture.md`  
Efficiency runbook: `references/efficiency-playbook.md`

## Super Mind definition

```text
SUPER MIND = Orchestrator + Specialists + Memory pyramid
           + Heal immune system + CI guardian + Constitutional locks
```

Not one giant prompt — a coordinated ecosystem that perceives, remembers, specializes, heals-first, routes credit-aware, locks identity, and publishes truth.

## Free-tier hard rules

| Allowed | Forbidden in learn loop |

## Run (autonomous cycle)

```bash
bash scripts/pke-learn.sh          # heal → observe → score → improve → stamp
bash scripts/pke-learn.sh --push   # + publish lessons/skill patches
bash scripts/ci-validate-skills.sh # structural guardian (true parallel)
```

Default is **on-demand** so startup stays fast. Permanent activation keeps this skill online across chat, iOS, web, Build.

## Cycle pipeline (OODA + heal-first)

```text
1. HEAL       pke-self-heal.sh (+ Raft-lite lease if multi-writer)
2. OBSERVE    validate · assets · heal-logs · app gate · CI signals
3. ORIENT     scores · failure_counts · top failure classes
4. DECIDE     gaps · missing sections · trigger breadth · splits
5. ACT        patch skill docs / references (local text only)
6. REMEMBER   mind/state.json + lessons.md + cycle report
7. PUBLISH    optional --push · CI re-validates
```

Creative wants diversity; heal wants one action — different algorithms per layer.

## Efficiency (non-negotiable)

1. Heal before improve.  
2. Local text intelligence over cloud vanity gens.  
3. Progressive disclosure — lean SKILL.md, deep references/.  
4. True parallel validation (authoritative status files; no sequential re-run).  
5. Smallest skill set for the job (use swarm sequences).  
6. Bounded loops (max 5 iterations; lease TTLs).  
7. Agent meetings only on real cross-skill conflict.  
8. Measure: overall score · CI wall · imagine_calls=0 on learn.

See `references/efficiency-playbook.md`.
